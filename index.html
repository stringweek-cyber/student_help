나이스 출결 도우미

한 달 치 출결 파일을 나이스 일일출결관리(담임용) 화면에 자동으로 입력해요. 저장과 마감은 선생님이 직접 해요.

1출결 자료 넣기

출결앱에서 내보낸 CSV를 그대로 불러오면 돼요. 직접 쓸 때는 열 순서 날짜, 번호, 구분, 교시, 사유로 출석이 아닌 학생만 적어요.

입력할 달 연도 생략 시(예: 11/3)
작성 규칙 보기
  • 날짜: 2026-11-03, 2026.11.03, 20261103, 11/3 모두 가능
  • 구분: 질병·미인정·기타·출석인정 + 결석/지각/조퇴/결과 (예: 미인정지각)
  • 교시: 결석은 비워두면 하루 전체(마감 칸). 지각·조퇴·결과는 꼭 적어요 → 1, 3-4, 1,3, 조회, 종례
  • 사유: 비워도 돼요
  • 출결앱 CSV: 출결유형+출결사유로 구분을 만들어요 (예: 지각+미인정 → 미인정지각, 결석+인정 → 출석인정결석). 나이스 사유 칸에는 출결상세와 메모가 들어가요.

2확인하기

자료를 넣으면 여기에서 검사해요
날짜번호구분클릭할 칸사유상태

3나이스에서 실행하기

오류가 없어야 복사할 수 있어요
  1. 나이스 학급담임 → 출결관리 → 일일출결관리(담임용) 화면을 열고 학년·반을 맞춰요.
  2. F12 → Console(콘솔) 탭에서 붙여넣고 Enter. (막히면 allow pasting 입력 후 다시)
  3. 오른쪽 아래에 출결 입력 패널이 떠요. 날짜 옆 [입력]을 누르면 그 날짜로 이동해 칸을 채워요.
  4. [▶ 전체 자동 실행]을 누르면 날짜마다 입력 → 저장 → 다시 조회해 저장 확인까지 하고 다음 날짜로 넘어가요. 문제가 있는 날에서 멈춰요.
처음엔 한 날짜만 넣어 보고 결과를 확인하세요. 실패가 하나라도 있는 날은 저장하지 않고 멈춰요. 이미 다른 값이 있는 칸은 건드리지 않아요. 출결마감은 자동으로 누르지 않으니, 끝나면 전체를 확인하고 직접 마감하세요.
