날짜번호구분칸사유상태

2나이스에서 실행

📋 나이스 출결입력 ← 이 버튼을 즐겨찾기 막대로 끌어다 놓기 (처음 한 번)
  1. 나이스 일일출결관리(담임용) 화면을 열어요.
  2. 즐겨찾기의 📋 나이스 출결입력을 눌러요.
  3. 패널에 비밀번호 → 파일 놓기 → [▶ 전체 자동 실행]
끌어다 놓기가 안 될 때
  1. Ctrl+Shift+B로 즐겨찾기 막대를 켜고 다시 끌어 보세요.
  2. 또는 → 즐겨찾기 막대 우클릭 → 즐겨찾기 추가 → 이름 아무거나, URL에 붙여넣기
  3. 그래도 안 되면 → 나이스에서 F12 → 콘솔에 붙여넣기
